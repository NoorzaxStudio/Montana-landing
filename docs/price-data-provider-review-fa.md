# بررسی سرویس‌های جایگزین داده قیمت

تاریخ بررسی: ۱۲ نوامبر ۲۰۲۶

## خلاصه پیشنهاد

- برای نیاز فعلی، **NerkhAra بهترین گزینهٔ رایگانِ بدون کلید برای پایلوت است**: یک endpoint عمومی هر چهار قلم را می‌دهد و از خود محیط پروژه هم پاسخ `200` گرفتیم. داده‌ها هر ۱۰ دقیقه بازسازی می‌شوند، پس برای قیمت‌های ثانیه‌ای مناسب نیست؛ دقت مستقل هم هنوز مقایسه نشده است. نمایش باید نام و لینک NerkhAra و زمان دریافت نرخ را حفظ کند.
- در پاسخ زنده‌ای که بررسی شد، دلار آزاد و طلای ۱۸ عیار میانگین دو منبع بودند؛ یورو از دلار بازار آزاد و نرخ جهانی مشتق شده بود؛ برای BTC فیلد `price_irt` به‌عنوان میانگین قیمت صرافی‌های ایران به تومان مستند شده است. NerkhAra برای استفادهٔ تجاری رایگان است، اما ضمانت دقت/دسترس‌پذیری نمی‌دهد و می‌گوید حقوق دادهٔ منبع‌های زیربنایی را اعطا نمی‌کند.
- **Iran Market Data** هم JSON عمومی بدون کلید دارد، اما چرخهٔ بازسازی‌اش ۳۰ دقیقه است؛ برای تابلوی قیمت زنده کندتر از NerkhAra است.
- **Talasanj** نرخ دلار و طلا را با چرخهٔ حدود ۲۰ ثانیه و پلن رایگان ۲۰٬۰۰۰ درخواست روزانه می‌دهد، ولی برای استفادهٔ پایدار به کلید رایگان و attribution قابل مشاهده نیاز دارد و API مستندشده EUR و BTC را پوشش نمی‌دهد.
- برای دلار آزاد، یورو و طلای ۱۸ عیار، **Navasan** گزینه‌ای با مستندات فنی عمومی‌تر است: نمادهای مشخص، زمان به‌روزرسانی، پاسخ JSON و سقف درخواست مستند دارد. برای قیمت‌های تازه‌تر، پلن Standard مستندشده از ۴۲ درخواست در ساعت پشتیبانی می‌کند. با این حال، خود Navasan دقت را تضمین نمی‌کند و پیش از خرید باید واحد نرخ یورو، HTTPS و اجازه نمایش عمومی داده را کتبی تأیید کرد.
- **Arzhaam** یک گزینه یکپارچه‌تر برای پایلوت است: مستنداتش HTTPS، قیمت تومان، کلید در هدر و endpoint نرخ چنددارایی با `updatedAt` و `cacheAgeMs` را اعلام می‌کنند؛ فهرست دارایی‌ها نیز EUR و BTC را دارد. اما ادعای «live» و دقت داده از طرف خود فروشنده است و SLA/بنچمارک مستقل در منابع بررسی‌شده پیدا نشد. قبل از انتخاب باید نمادهای لازم و سهمیه/هزینه پلن در داشبورد تأیید و از محیط deploy اندازه‌گیری شود.
- برای بیت‌کوین، قیمت مستقیم بازار محلی از جفت‌ارز **BTCIRT در Nobitex** از برآورد `BTC/USD × USD/IRT` نماینده‌تری از قیمت همان بازار است. این قیمت متعلق به یک صرافی است و باید با نام منبع و زمان به‌روزرسانی نمایش داده شود. پیش از نمایش، واحد دقیق `IRT` را در برابر تومان بررسی کنید.
- **TGJU** هم وب‌سرویس پولی برای نمایش نرخ در وب‌سایت‌های دیگر دارد و نرخ ارز آزاد و طلا را پوشش می‌دهد. مستندات رسمی می‌گویند داده هم‌زمان با سایت مبدأ به‌روزرسانی می‌شود و JSON/XML و توکن دارد؛ اما مبلغ، محدودیت فراخوانی و مشخصات اتصال در صفحه‌های عمومیِ بررسی‌شده معلوم نبود و باید از فروشنده استعلام شود. در نتیجه، endpoint عمومی فعلی `call1.tgju.org/ajax.json` را نباید معادل یک API قراردادی و مستند فرض کرد.
- **Wallex** می‌تواند گزینه دوم برای قیمت رمزارز محلی باشد؛ API عمومی آن قیمت و پرچم بازار تومانی را برمی‌گرداند، اما اسناد بررسی‌شده وجود بازار فعال BTC/TMN یا محدودیت نرخ درخواست را تضمین نمی‌کنند. فهرست بازارهای زنده را باید هنگام پیاده‌سازی بررسی کرد.

این بررسی کیفیت بازار را به‌صورت مستقل benchmark نکرده است؛ فقط یک latency نمونه برای endpoint عمومی NerkhAra از محیط پروژه اندازه‌گیری شد. timeoutهای قبلی TGJU و Coinbase ثابت نمی‌کنند همهٔ منابع غیرقابل‌دسترسی‌اند؛ درخواست مستقیم NerkhAra از همان محیط موفق شد.

## گزینهٔ رایگان بدون کلید: NerkhAra

API رسمی `GET https://nerkhara.com/api/v1/latest.json` احراز هویت نمی‌خواهد و JSON شامل نمادهای `usd`، `eur`، `gold-18k` و `btc` است. همهٔ نرخ‌های `IRT` در قرارداد آن به معنی تومان (نه ریال) هستند. برای بیت‌کوین باید `price_irt` را بخوانیم، چون `price` معمولی با واحد `USDT` است. فیلدهای `updated_utc` و `stale` برای بررسی زمان و تازگی هر قلم موجودند.

**آزمون مستقیم از همین محیط پروژه در ۱۲ نوامبر ۲۰۲۶:** endpoint بدون کلید پاسخ `200` داد؛ زمان پاسخ اندازه‌گیری‌شده حدود ۰٫95 ثانیه بود. `generated_utc` برابر `2026-11-12T09:17:07` بود و چهار قلم همگی `stale: false` و `updated_utc: 2026-11-12T09:14:43` داشتند. نمونهٔ همان پاسخ: USD = 266,755 تومان، EUR = 296,427 تومان، گرم طلای ۱۸ عیار = 25,399,581 تومان و BTC از فیلد `price_irt` = 19,586,784,283.5 تومان. این فقط یک نمونهٔ زمانی است، نه benchmark پایداری یا تضمین قیمت.

مستندات می‌گویند چرخهٔ دریافت/بازسازی داده هر ۱۰ دقیقه است؛ بنابراین تازگی عملی از سرویس‌های ۲۰ثانیه‌ای پایین‌تر است. طبق روش اعلام‌شده، دلار از میانگین دو ناشر بازار تهران و طلای ۱۸ عیار از منابع بازار محاسبه می‌شود؛ یورو نرخ مستقیم صرافی نیست و از دلار آزاد به‌علاوهٔ نرخ جهانی مشتق می‌شود. شرایط API استفادهٔ تجاری را با attribution نام «NerkhAra»، لینک در کنار داده و نگه‌داشتن timestamp مجاز می‌داند؛ صریحاً ضمانتی برای دقت/دسترس‌پذیری نمی‌دهد و حقوق منبع‌های زیربنایی را اعطا نمی‌کند.

## جزئیات منابع

### NerkhAra

صفحهٔ API رسمی endpoint عمومی `latest.json` و نسخهٔ تک‌نماد را معرفی می‌کند؛ index رسمی نیز واحد `IRT` را تومان تعریف کرده و صریحاً attribution و زمان خواندن را جزو شرایط مصرف قرار می‌دهد. در پاسخ لحظه‌ای، ارزها و طلا از روش `average` و `sources` استفاده می‌کنند؛ API برای هر قلم `updated_utc`، `stale`، `method` و در صورت وجود `spread_pct` برمی‌گرداند. چرخهٔ ۱۰ دقیقه‌ای و منابع ادعاشده در صفحهٔ روش‌شناسی همان سرویس توضیح داده شده‌اند.

### Navasan

راهنمای رسمی API، میزبان `api.navasan.tech`، endpoint مربوط به آخرین قیمت‌ها، JSON، کلید اجباری و فیلدهای مقدار، تغییر و زمان/تاریخ را شرح می‌دهد. کدهای مستندشده شامل `usd_sell` (فروش دلار تهران)، `usd_buy` و `18ayar` (گرم طلای ۱۸ عیار) است. صفحه راهنما برای `eur` عنوان «یورو» را دارد، ولی تعریف دقیق بازار آن را در برابر نرخ آزاد تهران روشن نمی‌کند؛ این مورد باید از پشتیبانی پرسیده شود.

صفحه پلن‌ها برای رایگان، به‌روزرسانی هر دو ساعت و ۱۲۰ درخواست ماهانه؛ برای Standard، به‌روزرسانی لحظه‌ای و ۴۲ درخواست در ساعت، ۱۰۰۰ در روز، ۳۰هزار در ماه را درج کرده است. Standard در همان صفحه ۳۰ دلار برای شش ماه یا ۵۵ دلار برای دوازده ماه درج شده؛ قیمت و شرایط پیش از خرید باید دوباره با فروشنده تأیید شود. توضیح سلب مسئولیت Navasan می‌گوید داده از منابع مختلف گردآوری می‌شود و صحت آن تضمین نمی‌شود.

برای کش مشترک سمت سرور با بازه ۵ دقیقه، ۱۲ درخواست در ساعت، ۲۸۸ درخواست در روز و ۸۶۴۰ درخواست در ماه لازم است؛ این مقدار زیر سهمیه Standard مستندشده است، به شرط آنکه فراخوانی بین کاربران و instanceهای برنامه مشترک باشد و برای هر بازدیدکننده جداگانه API صدا زده نشود.

### Arzhaam

مستندات رسمی `https://arzhaam.ir` را Base URL با HTTPS و واحد پاسخ را تومان اعلام می‌کند؛ کلید باید در هدر `X-App-Key` قرار بگیرد. endpoint نرخ‌های لحظه‌ای چند دارایی، `updatedAt` برای هر نرخ و `cacheAgeMs` و `source` را در meta برمی‌گرداند. مستندات asset list شامل `eur` و `btc` است و برای نرخ‌ها، پلن آزمایشی ۵ روزه و سقف ۱۰ درخواست در دقیقه، ۲۰۰ در ساعت، ۱۰۰۰ در روز را درج می‌کند. این‌ها مشخصات منتشرشده فروشنده هستند، نه اندازه‌گیری مستقل از uptime یا دقت. Trial مناسب است تا از سرور واقعی latency، تازگی timestamp، درصد خطا و تطبیق نرخ‌های USD/EUR/طلای ۱۸ عیار/BTC سنجیده شود.

### TGJU

راهنمای رسمی TGJU توضیح می‌دهد که وب‌سرویس برای مدیران/برنامه‌نویسان وب‌سایت است، داده‌ها را برای نمایش در سایت مقصد می‌دهد، از JSON و XML پشتیبانی می‌کند و برای سفارش، کاربر بسته را می‌خرد و توکن و راهنمای فنی می‌گیرد. در روش وب‌سرویس، طبق همان راهنما نوسانات هم‌زمان با سایت مبدأ در مقصد نمایش داده می‌شوند. راهنما همچنین می‌گوید سرویس شامل بسته‌های جداگانه است و قیمت هر بسته، تعداد درخواست مجاز و مدت استفاده باید در صفحه همان محصول دیده شود؛ ولی رقم آن‌ها در صفحات عمومی‌ای که بررسی شد در دسترس نبود.

### Nobitex و Wallex

مستندات رسمی Nobitex، endpoint عمومی `GET /v3/orderbook/BTCIRT` را بدون نیاز به token معرفی می‌کنند و پاسخ نمونه آن `lastTradePrice` و `lastUpdate` دارد. برای endpoint بازارها نیز توصیه می‌کنند درخواست‌ها با فاصله دست‌کم ۱ تا ۱۰ ثانیه ارسال شوند، چون درخواست سریع‌تر می‌تواند همان داده cache شده را برگرداند. ۳۰۰ درخواست در دقیقه سقف منتشرشده برای orderbook است؛ برای یک نوار قیمت نیازی به polling نزدیک این سقف نیست.

مستندات Wallex، endpoint عمومی فهرست بازارها را با قیمت، دارایی quote و فیلد `is_tmn_based` نشان می‌دهند. این فیلد کمک می‌کند بازارهای دارای quote تومانی شناسایی شوند، ولی مستندات بررسی‌شده ثابت نمی‌کنند که BTC/TMN در لحظه انتخاب‌شده فعال است.

### قیمت جهانی

Coinbase توضیح می‌دهد که product ticker، آخرین معامله و بهترین bid/ask را برای یک محصول برمی‌گرداند و برای داده لحظه‌ای استفاده از WebSocket را به‌جای polling REST توصیه می‌کند. CoinGecko endpoint قیمت را با شناسه کوین می‌دهد و فیلد `last_updated_at` را برای تشخیص تازگی مستند کرده است. این داده‌ها برای مرجع جهانی مناسب‌اند، اما با نرخ نقدی آزاد ایران یا معامله BTC/IRT یکی نیستند.

## گام پیشنهادی پیش از تغییر کد

۱. برای پایلوت رایگان، چهار شناسه را از NerkhAra بگیریم و برای BTC از `price_irt` استفاده کنیم.
۲. attribution لینک‌دار و زمان نرخ را کنار تابلو حفظ کنیم؛ دادهٔ stale یا timestamp قدیمی را نمایش ندهیم.
۳. روی چند روز، نرخ‌ها و latency را در برابر منبع دوم مقایسه کنیم، به‌ویژه نرخ مشتق‌شدهٔ EUR و بازار BTC محلی.
۴. اگر دقت/تازگی کافی نبود، Talasanj برای USD/طلا یا API پولی/کلیددار برای پوشش کامل را جداگانه ارزیابی کنیم.
