# Montana landing (Next.js)

صفحه فرود مونتانا: فارسی/انگلیسی، روشن/تیره، و قیمت‌های لایو.

## ساختار
- `app/markup.js` متن و ساختار صفحه (فارسی، با ترجمه انگلیسی در `data-en`)
- `app/globals.css` طراحی
- `public/landing.js` دکمه‌ها، قیمت‌ها، نوار TradingView
- `app/api/prices` قیمت دلار، یورو و طلای آب‌شده از tgju (بازار آزاد) و بیت‌کوین از Coinbase ضرب در دلار آزاد. هر ۶۰ ثانیه به‌روز میشه.
- `app/privacy` صفحه حریم خصوصی

## دیپلوی (GitHub + Vercel، رایگان)
1. یه ریپوی جدید تو GitHub بساز و همه فایل‌های این پوشه رو آپلود کن (Add file > Upload files).
2. برو به vercel.com، با حساب GitHub وارد شو، Add New > Project، ریپو رو انتخاب کن.
3. قبل از Deploy، تو بخش Environment Variables فقط `NEXT_PUBLIC_SITE_URL` رو بذار (آدرس نهایی سایت، مثلاً https://montana.com).
4. Deploy رو بزن. از این به بعد هر تغییری تو GitHub بدی، خودکار روی سایت میره.
5. برای دامنه خودت: Project > Settings > Domains.

## تست بعد از دیپلوی
- `https://آدرس-سایت/api/prices` باید عدد دلار، یورو، طلا و بیت‌کوین رو نشون بده.

## اجرا روی کامپیوتر خودت
```
npm install
cp .env.example .env.local
npm run dev
```

## ربات تلگرام (@Montanatraderbot)
فایل‌ها در `bluehost/bot/` هستن و با بقیه سایت روی بلوهاست میرن (آدرس: `/bot/`).
- `lib-content.php` همه متن‌ها، عکس‌ها، دکمه‌ها، لینک کانال و توضیحات ربات
- `img/` عکس هر بخش
- `index.php` وب‌هوک، حول منتورشیپ آنلاین: استارت = ۴ مزیت + معرفی دوره و ویدیو مسیج؛ دکمه‌ها: سرفصل‌های دوره، معرفی استاد (۴ پیام با فاصله ۳ ثانیه)، ثبت‌نام رایگان (نام، موبایل، شهر، سال تولد) و لینک کانال تحلیل‌ها
- ثبت‌نام‌های ربات کنار ثبت‌نام‌های سایت در `~/montana-stats/leads.csv` ذخیره میشن (منبع `telegram-bot`، تب منتورشیپ پنل ادمین) و به گوگل شیت و ادمین ربات هم فرستاده میشن
- `setup.php` راه‌اندازی یک‌باره: توکن از @BotFather رو اینجا بذار. وب‌هوک، توضیحات، About و منوی دستورها رو خودش تنظیم می‌کنه و کد `/admin` رو نشون میده
- تنظیمات و داده‌ها در `~/montana-stats/bot.json` (بیرون از پوشه عمومی)

دستورهای ادمین در خود ربات: فرستادن ویدیو مسیج (بعد انتخاب بخش: خوش‌آمد، سرفصل‌ها یا معرفی استاد)، `/videos` و `/stats`.

ربات قبلی (کپی‌ترید) در `archive/telegram-bot-copytrade/` نگه داشته شده و دیپلوی نمیشه.
